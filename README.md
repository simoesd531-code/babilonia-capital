## PASTAS:
- index.html -> site principal
- admin.html -> painel de admin (senha: babilonia2026) - troque no código
- data/testimonials.json -> depoimentos (você edita via admin e cola aqui)
- data/free-content.json -> PDFs gratuitos

## COMO ATUALIZAR:

### Depoimentos:
1. Abra https://seusite.github.io/babilonia-capital/admin.html
2. Senha: babilonia2026
3. Adicione depoimento, clique Adicionar, Copiar JSON
4. No GitHub: vá em data/testimonials.json > lápis > cole > Commit
5. Em 1-2 min aparece no site

### Adicionar PDF gratuito:
1. GitHub > assets > Add file > Upload files > envie o PDF
2. GitHub > data/free-content.json > edite e adicione novo objeto
3. Commit

### Trocar textos do site:
Tudo em index.html - só editar e Commit.
